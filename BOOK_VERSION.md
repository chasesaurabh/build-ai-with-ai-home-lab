This working tree contains revised projects and reader walkthroughs. It is not the
first-edition release. Do not use the old tag to reproduce the revised chapters.
Record `git rev-parse HEAD` plus `git status --short` with every run. Acquire the
public immutable tag and compare its commit with the one printed in your book;
do not substitute a mutable branch if a tag cannot be obtained. A local copy
does not establish public release availability. A code tag does not by itself
assign the book's retail edition number.
