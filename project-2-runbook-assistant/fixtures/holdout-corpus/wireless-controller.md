# Wireless Controller Operations

## Client Authentication Failures

Repeated client authentication failures can involve credentials, certificate validation, time synchronization, or policy assignment. Record the client identifier, access point, network name, time window, and bounded authentication log excerpt.

## Coverage Degradation

For reported coverage degradation, compare affected locations, client types, signal observations, interference indicators, and recent access-point changes. Do not increase transmit power automatically from an informational diagnosis.

## Firmware Change Boundary

A controller firmware update requires a maintenance window, compatibility review, configuration backup, validation plan, and rollback image. A runbook answer cannot schedule or apply the update.
