# Security Policy

## Intended use

These projects are teaching prototypes for synthetic, disposable home-lab environments. They are not production-ready services and do not include a complete authentication, authorization, TLS, multi-user isolation, monitoring, privacy, or incident-response design.

Do not submit real credentials, private logs, personal data, or irreplaceable configuration. Keep model and application endpoints loopback-only unless you have independently designed and tested the broader exposure.

## Reporting a problem

After the public repository is created, report security issues through the repository's private security-advisory feature. Do not place secrets, exploit details, private infrastructure identifiers, or user data in a public issue.

For ordinary correctness problems that do not expose sensitive information, open an issue with a minimal synthetic reproduction, expected behavior, observed behavior, project name, release tag, and dependency versions.

## Supported release

Only the book-aligned `book-v1.0.0` release will be supported initially. The tag and public URL are pending.
